# Controle de Finanças Android

Projeto nativo Android em Kotlin com Jetpack Compose e Material 3.

A aplicação web original permanece na raiz do repositório e é usada como referência funcional durante a migração.

## Requisitos

- Android Studio Ladybug ou mais recente
- JDK 17
- Android SDK 35

Abra a pasta `android/` no Android Studio para sincronizar o Gradle e executar o aplicativo.
